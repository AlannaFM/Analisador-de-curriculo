<h1 align="center">ScoreWise</h1>

###

<p align="left">Feito a partir do video "Build and Deploy a Full AI-Powered Applicant Tracking System" do canal JavaScript Mastery, o ScoreWise é um analisador de currículos com IA que atua como um sistema pessoal de rastreamento de candidatos (ATS). Ele permite que os usuários enviem seus currículos, comparem-nos com descrições de vagas específicas e recebam uma pontuação de compatibilidade, além de feedbacks detalhados gerados por inteligência artificial para melhorar suas chances de contratação.</p>

### ➤ Tecnologias Utilizadas

* **React** - Interface do usuário e componentes.
* **React Router** - Gerenciamento de rotas.
* **Puter.js** - Autenticação serverless, armazenamento de arquivos e serviços de IA.
* **Tailwind CSS** - Utilitário para design rápido e responsivo.
* **TypeScript** - Adiciona tipagem estática ao JavaScript.
* **Vite** - Ferramenta de build para o React.
* **Zustand** - Gerenciamento de estado global.
* **Junie** - Agente de IA da JetBrains.

###

<h3 align="left">➤ Funcionalidades</h3>


<p align="left">‧ Autenticação simples via puter.js.<br>‧ Análise com IA.<br>‧ Pontuação ATS.<br>‧ Feedback personalizado. <br>‧ Rota "/wipe" para limpar os dados.</p>
